【填写：受【建设单位】委托，对【系统名称】（版本号【填写】）开展上线前安全检测，验证其具备上线条件。】

- 系统类型：【网站 / Web 系统 / 小程序（uni-app、Taro 跨端注明）】
- 部署形态：【公有云 / 私有云 / 本地机房 / 微信云开发】
- 检测性质：【首次上线 / 重大变更 / 复测 / 年度检查】

# 检测依据

| 层级 | 依据 | 用途 |
|---|---|---|
| 法律法规 | 《网络安全法》《数据安全法》《个人信息保护法》《网络数据安全管理条例》 | 合规底线 |
| 国家标准 | GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》（现行，全文见全国标准信息公共服务平台 openstd.samr.gov.cn）、GB/T 28448-2019、GB/T 35273-2020 | 定级与测评引用 |
| 国际实践 | OWASP Top 10:2025（重点引用 A03 软件供应链失效）、OWASP API Security Top 10、CVSS 3.1 | 漏洞定级依据 |
| 平台规范 | 微信小程序平台运营规范、用户隐私保护指引（涉及小程序时） | 过审与平台合规 |
| 项目文件 | 【填写：需求文档、设计方案、被测单位安全管理制度】 | 范围与口径 |

# 检测内容与方式

按控制域组织，检测结果逐项写入《系统上线安全检测和安全措施有效性验证报告》第 5 章结果记录表。标记说明：[自]=工具自动化，[人]=必须人工，[半]=工具辅助加人工判断。

## 身份鉴别与授权管理

- [半] 未授权访问：去除 Token/Cookie 后接口是否仍返回数据。
- [人] 水平/垂直越权与 IDOR 遍历：修改 user_id、order_id、role 参数验证。
- [人] 口令策略、防暴力破解锁定、账号生命周期与共享账号核查。
- [自] 特权账号默认口令与中间件管理面核查。

## 输入验证与会话管理

- [自] SQL 注入、命令注入、XSS、SSRF 扫描（覆盖全部外部输入点）。
- [人] 文件上传类型/大小/内容校验与存储路径可执行性测试。
- [自] 会话超时、Cookie 属性（HttpOnly/Secure/SameSite）、会话标识随机性与失效机制。

## 密码学与传输安全

- [自] TLS 版本与证书链、HTTP 跳转、混合内容检查。
- [半] 口令散列与敏感字段加密存储核查（要求提供配置或代码证据）。
- [人] 密钥管理制度与前端硬编码密钥检查。

## 业务逻辑安全（自动化扫不出，人工为主）

- [人] 支付与金额篡改、回调验签、重复下单幂等。
- [人] 优惠券/权益复用、并发超发、验证码爆破与重放。
- [人] 流程绕过与状态机回退、预约/排队资源被脚本占满。

## API 与中间件安全

- [半] 接口认证、限流、防重放、返回字段脱敏。
- [自] 中间件版本漏洞、默认组件、管理端口收敛、日志留存核查。
- [自] 软件供应链：依赖清单（SBOM）、已知 CVE（CVE/NVD/OSV 订阅）、停维组件、官方源与签名包、CI/CD 职责分离与变更记录、灰度发布（OWASP Top 10:2025 A03）。

## 云暴露面

- [自] 存储桶枚举与公开读写检测（scripts/cloud：brute-s3、check-bucket、scan-bucket）。
- [自] SSRF 至云元数据服务探测（probe-ssrf）。
- [自] K8s API/Kubelet/etcd 未授权探测（probe-k8s）；容器逃逸条件检测（container-escape，仅检测不利用）。
- [人] 报错泄露、非正式镜像、部署文档与代码托管平台泄露排查。

## IPv6 支持度

- [自] AAAA 解析、IPv6 源可达性、双栈功能一致性。

## 个人信息保护（小程序与面向个人的系统必测）

- [人] 隐私政策与实际收集行为一致性、告知-同意、最小必要、单独同意。
- [人] 撤回同意与注销删除机制、第三方 SDK 披露。

## 安全管理制度（访谈与文档查验为主）

- [人] 安全管理制度、操作规程、应急预案齐备性与现行有效性。
- [人] 安全机构与人员：专岗设置、职责书面化、人员离岗交接、安全意识培训。
- [人] 系统建设管理：上线前强制安全检测流程、变更与发布审批留痕。
- [人] 运维管理：补丁更新周期、应急演练记录、日志审计周期、备份策略与恢复验证。

|---|---|---|---|

| 2 信息收集 | 域名/子域名/端口/接口盘点，云暴露面枚举 | 【填写】 | 资产与暴露面清单 |
| 3 静态审计 | 代码/包反编译、硬编码与危险逻辑检查 | 【填写】 | 静态问题清单 |

| 5 合规核查 | 隐私与平台规范逐项核对、配置基线核查 | 【填写】 | 核查记录 |

# 风险与约束

1. 所有检测在书面授权范围内执行，未授权目标一律不测；渗透测试时间窗口为【填写】。
2. 自动化扫描控制速率避免影响生产；写操作类验证（文件上传、下单）使用测试账号。
3. 云凭证探测默认只读（DryRun/假参数）；实际利用操作（建用户、改策略）须另行书面确认。
4. 生产环境执行的高危用例已通知运维并具备回退条件。
